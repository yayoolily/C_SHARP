#chepter one practice 

## Overview

this practice would cover how to :

-display a message using messageBox 
-display text using a label control
-clear text from a label control

##display a message using messageBox  
 
the messageBox.show() method is used to display a message and accepts only string 

![messageBox](Screenshot/messageBox.png)


##displaying text using a label

 the text property is used to display text inside a label control
 

syntax:
labelName_.text _ equal sign "=" _ qountations "";
item receiving value must be on the left of the  equal "=" operator
and text property also accepts only string

![messageBox](Screenshot/displayoutputusinglabel.png)


## clearing the  label

the label text can be cleared by assigning an empty string  "" or using string.empty
