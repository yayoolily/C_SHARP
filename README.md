Course Title: Visual Programming (C#.NET)
Prerequisites: Programming

Course Objectives

- This course incorporates the basics concepts of C#programming , problem solving and programming logic , as well as the design techniques of an object-oriented , event-driven language 
- A high priority is given to writing applications that are easy for the user to understand and to use
- The course  is rich in concise , practical , and real_world examples programs, so the student not only learn how to use the virous controls , constructs and features of Visual C#, but also learns why and when to use them
